# 18 — Flexbox App Layout

Відновлено за скріншотами 168–180. Показані ключові властивості `.app-wrap {display:flex; flex-direction:column}`, `.app-wrap > * {flex:1 1 auto}`, `.app-header {display:flex;align-items:center;justify-content:space-between}`, `.content {overflow-y:scroll;-webkit-overflow-scrolling:touch}` і `.icon-bar {display:flex}`, `.icon-bar a {flex:1}` (останній фрагмент також видно на пов'язаних скріншотах у розмові). HTML відтворює видиму структуру. Оригінальне фото з відео не додається; фоновий медіафайл відсутній. Іконки відновлено через класи Font Awesome 4.3.0, URL CSS видно на скріншоті; для показу іконок потрібен інтернет. Деякі косметичні стилі реконструйовано, оскільки вони не повністю видимі. Вміст `examples` — проміжні стани, а не дослівні повні копії CSS автора.

Додано окремі проміжні CSS-етапи для `.icon-bar {display:flex}` і `.icon-bar a {flex:1}`. Оригінальний URL портретного фото на скріншотах обрізаний, тому він не вигадувався й фото не додано.
