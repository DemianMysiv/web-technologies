# Урок 4 — Wrapping elements with Flexbox

Основна демонстрація `display:flex` і `flex-wrap:wrap` зі зміною ширини блоків (кадри, раніше збережені у папці уроку 3). `examples/` зберігає перехід від фіксованої ширини до перенесення та багатоколонного компонування. Це тематичне розділення наявної реконструкції, а не новий дослівний запис лекції.
