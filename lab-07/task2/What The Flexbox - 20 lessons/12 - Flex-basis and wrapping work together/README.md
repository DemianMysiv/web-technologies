# Урок 12 — How Flexbox’s flex-basis and wrapping work together

Повторно виділені кадри з `flex-direction:column`, `flex-wrap:wrap`, `flex-basis`, `flex-grow` та перевизначенням базового розміру четвертого блока. Оригінальні CSS-стани доступні у `examples/`. Деякі фрагменти спільні з уроком 11 — повтор збережено свідомо для самодостатньої папки.
