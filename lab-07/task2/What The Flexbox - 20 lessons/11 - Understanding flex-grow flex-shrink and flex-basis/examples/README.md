# Скриншоти №61–71

- №61–64 — пояснення `flex: 1`, `flex-grow`, `flex-shrink`, `flex-basis`. На №61–62 показано три незаповнені властивості, які не є валідною фінальною конфігурацією. №63 — `flex-grow:1`; №64 — `flex-grow:1` і `flex-shrink:1`.
- №65 — однакове `flex-basis:400px` для `.box1` та `.box2`.
- №66 — `flex-basis:400px` для обох; `flex-grow:10` і `flex-shrink:5` для першого; `flex-grow:1` і `flex-shrink:1` для другого.
- №67 — узагальнення першого і другого через `flex:10 5 400px` і `flex:1 1 400px` (той самий принцип, знятий на сусідніх кадрах).
- №68 — `flex-wrap:wrap`, `flex-basis:500px`.
- №69 — `flex-direction:column`, властивості розмірів тимчасово закоментовано.
- №70 — `flex-wrap:wrap; flex-direction:column`, `border:10px solid goldenrod`, `min-height:100vh`, базовий розмір 250px, зростання `.box3` до 5.
- №71 — додано `.box4 { flex-basis:100px; }`.

Базовий CSS нормалізації та частина HTML поза кадром реконструйовані; це не повний дослівний вихідний код курсу. Для №61–62 незавершені декларації не відтворювалися як виконувані CSS-файли.

**№100** — коротке повернення до `flex-basis:400px` для `.box1` і `.box2`; дубль прикладу №65, додано окремий стан `10-revisited-equal-basis-400px.css`.

## №101–108 (повернення до grow/shrink)

На кадрах послідовно порівнюються `flex-basis:400px`, `flex-grow:1/2/10` і `flex-shrink:1/5/10`. Перший і другий елементи одержують різні коефіцієнти; при достатньому просторі працює `grow`, а при нестачі — `shrink`, з урахуванням базового розміру. Записи `flex:10 5 400px` та `flex:1 1 400px` — скорочена форма відповідних трьох властивостей. Проміжні знімки відтворені окремими CSS-файлами 11–16; це нормалізовані робочі стани, а не піксельно точні копії кожного кадру.
