## Запуск

Відкрийте `index.html` у папці потрібного уроку. `style.css` підключений локально. Для проміжного стану дивіться `examples/` (якщо існує). Деякі оригінальні зовнішні медіаресурси та CDN можуть бути недоступні; це не означає відсутності HTML/CSS.

## Межі реконструкції

Початкові файли збережені за змістом при перенумерації. Нові завдання та перепризначені уроки позначено у README. Проєкт не видає створені відсутні уроки за точні копії відео. Умовний CSS-only мобільний перемикач додано для робочої демонстрації.
